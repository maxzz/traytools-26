For the groups tree, it is necessary to implement a Drag and Drop operation initiated externally (i.e. not from application but for example from the Windows shell). 
If a drop happens on group element all file names from the drag and drop operation will be added to that group as new items. 
If the items are dropped onto empty space in the tree—specifically, below the last element or onto the root element—a new group will be created, and all items from the Drag and Drop operation will be added to it. 
If the items are dropped onto copy operation item all items from the drag and drop operation will be added to the parent group.	
It is also necessary to ensure there are no conflicts between drag-and-drop operations that reorder tree elements and drag-and-drop actions initiated from outside the application.
