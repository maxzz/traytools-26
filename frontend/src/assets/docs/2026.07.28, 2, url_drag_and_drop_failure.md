**Cursor**

I'll focus only on making HTTPS command values use the same text color as regular paths.

The faded HTTPS look is almost certainly from the disabled Reveal button: `InputGroup` uses `has-disabled:opacity-50`, so a disabled addon button dims the whole field—including the value.

Root cause: when the Command value is a URL, Reveal is `disabled`, and `InputGroup`'s `has-disabled:opacity-50` fades the whole field. Scoping that style to the input control only.

Fixed. HTTPS values weren’t styled differently on purpose — when the command was a URL, the Reveal button became `disabled`, and `InputGroup`’s `has-disabled:opacity-50` dimmed the **entire** field, so the text looked like a placeholder.

That opacity rule now applies only when the input itself is disabled, so URL and path values render the same.
