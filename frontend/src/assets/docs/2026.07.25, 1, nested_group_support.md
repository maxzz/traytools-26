Nested groups are supported in the copy-operations editor.

**Model:** `CopyGroup` now has optional `groups?: CopyGroup[]`. Nested groups and items can coexist under one group.

**Behavior:**
- **Add Group** with a group selected → nests inside that group; with **Groups** selected → root level
- **Drag-and-drop** onto a group (middle zone) nests a group; cycles are blocked
- **Copy group** flattens all descendant items and runs them with the selected group’s flags
- Tree renders nested groups (groups first, then items)
- `copy.json` round-trips nested `groups`; empty nested arrays are omitted

Existing flat configs keep working unchanged.
